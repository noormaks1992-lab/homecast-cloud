## Confirmed code defects addressed

- Reconfiguring the unchanged upstream during a relay restart invalidated the direct viewer's opaque segment URLs. Same-source recovery now preserves these URLs, including refreshed headers; an explicit source change/stop still invalidates them.
- Relay restart previously generated a new epoch-based sequence and replaced its window. Recovery now appends to the previous list, advances segment numbers, and marks discontinuities. A normalizer retains discontinuity numbers when markers leave the window.
- Missing segments were removed from arbitrary positions and the first media sequence was incremented for every missing item. Missing positions are now marked as HLS gaps without renumbering surviving media.
- A normally completed HLS playlist could enter an endless recovery loop. A clean exit with ENDLIST now ends the presentation.
- Application recovery had additional fixed delays, up to 15 seconds. The first retry is immediate; repeated failures back off, and upstream 429 Retry-After is respected. This does not remove network transfer time or the HLS library's own retry policy.

## Requested controls

- Removed the original-source/relay dropdown. The viewer starts on the direct HLS path when available. Auto quality can fall back to a fresh running relay after repeated fatal network errors or an empty-buffer stall. A fixed manual quality never silently changes to the highest relay quality.
- Quality choices remain visible. Close mode uses three target durations rather than chasing the last fragment. Startup has no synthetic waiting countdown; this is not zero-latency HLS.
- Per-channel administration: original audio, global mute, independent audio URL (audio-only or compatible video/page source), gain 0–200%, positive audio delay 0–30 seconds.
- External audio is decoded/validated before stopping the current channel. Validation does not block current playlist delivery. Invalid audio leaves the working selection intact.
- Video uses stream copy. Changed audio is AAC; a mute removes audio. Modified audio requires the relay's current single video quality; original source quality selection returns when the original audio/default gain/default delay are restored.
- Original direct routes are blocked while global audio processing is enabled, preventing a bypass of the broadcast audio setting. Buffered old media already downloaded cannot be retroactively changed.
- Public URL validation, channel isolation, owner/delegated-stream access, CSRF checks, and existing persistence are retained. Audio URLs are only present in owner status, not public viewer status.
- Owner status includes sanitized ingest/manifest diagnostics. No source tokens or URLs are added to logs.
